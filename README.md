🌐 Personal Portfolio
A modern, responsive personal portfolio website built to showcase my profile, technical skills, projects, certifications, and contact information.

🛠️ Tech Stack
- React 19
- Tailwind CSS
- Python
- FastAPI
- Axios

✨ Features
- Home and About sections
- Resume and Skills
- Services and Certifications
- Contact Form
- WhatsApp Integration
- Responsive Design
- Modern Dark-Themed UI

⚙️ Installation

**Frontend**
```bash
cd frontend
npm install
npm start
```

**Backend**
```bash
cd backend
pip install -r requirements.txt
```

🎯 Objective

To build a professional online presence and showcase my technical knowledge, projects, and achievements.
